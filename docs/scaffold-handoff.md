# 초기 뼈대의 임시 구현과 담당 범위

아래 코드는 작업 시작을 위한 임시 구현이며 최종 API 계약이나 디자인 규칙으로 확정하지 않는다.
담당자는 자신의 이슈에서 교체하거나 구조를 바꿀 수 있다.

| 영역                         | 후속 작업        | 담당   |
| ---------------------------- | ---------------- | ------ |
| 토큰 상태, ProtectedRoute    | VIDI-25, VIDI-27 | 김서현 |
| QueryClient, API 타입, Orval | VIDI-26          | 김서현 |
| Tailwind 테마·폰트·색상      | VIDI-33          | 김미리 |
| 버튼과 ScreenShell           | VIDI-34          | 김미리 |
| 오류·알림·404 화면           | VIDI-35          | 김미리 |

스타일은 Tailwind 유틸리티와 globals.css의 theme 토큰으로 작성한다.
색상·컴포넌트 API를 확정하는 규칙은 담당자의 20번대 문서에서 정한다.
이 문서는 담당자에게 작업을 넘기는 안내이며 10·20번대 규칙 본문을 대신하지 않는다.
